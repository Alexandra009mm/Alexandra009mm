**Data Engineering · Backend · AWS · ETL · Cloud Architecture**

- Integración de siete fuentes de datos mediante archivos, APIs REST, webhooks y sistemas transaccionales.
- Simuladores de transportadoras de tipos Push, Pull y Batch.
- Pipelines ETL, validación de datos, deduplicación y auditoría.
- Modelado dimensional y arquitectura de datos Bronze/Silver/Gold.
- Cálculo de SLA, alertas de riesgo y penalizaciones.
- Diseño de arquitectura AWS con Terraform, Docker y CI/CD.
- Documentación técnica mediante Docusaurus.

**Stack:** Python, PostgreSQL, Apache Airflow, Apache Spark, AWS, Docker, Terraform, RabbitMQ, FastAPI, Pytest y GitHub Actions.

### ☁️ Odoo SaaS — Multi-Tenant Cloud Architecture

**Cloud Engineering · AWS · Software Architecture · DevOps**

Diseño de una arquitectura SaaS para Odoo con aislamiento por cliente y despliegues contenerizados.

- Servicios independientes por cliente mediante ECS Fargate.
- RDS PostgreSQL, subdominios con Route 53 y balanceo mediante ALB.
- Provisionamiento desencadenado por botón mediante AWS Lambda.
- Secrets Manager, TLS, KMS, backups y versionado de datos.
- Diseño de CI/CD, control de versiones y estrategias de rollback.

**Stack:** AWS ECS Fargate, Lambda, RDS, S3, Route 53, ALB, CloudWatch, Secrets Manager, GitHub Actions y CodeBuild.

**Estado:** diseño de arquitectura y planificación técnica.
